# Guess a Number

A simple browser-based number guessing game where the player tries to guess a random number between 1 and 100 within 10 chances.

## Features

- Random number generation between 1 and 100
- 10 chances per round
- Feedback for high or low guesses
- Win and game-over states
- Replay option after the round ends
- Clean and responsive layout

## Project Files

- index.html — page structure
- style.css — styling and layout
- script.js — game logic

## How to Run

1. Open the project folder in a browser.
2. Open index.html directly in your browser.
3. Start guessing numbers from 1 to 100.

## Gameplay

- Enter a number between 1 and 100.
- Click the Check button.
- If your guess is too high, you will be told it is high.
- If your guess is too low, you will be told it is low.
- You win if you guess the correct number before using all 10 chances.
- The game resets when you click Replay.
